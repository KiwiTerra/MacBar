# MacBar interface

The user's explicit choice of Windows 11-style grouped icons overrides concept exploration. Native desktop utility; Operate mode. Build directly in native UI to validate real window behavior, not with bitmap mockups.

- 56 pt horizontal bar, flush with the usable screen edges, zero outer or container padding. Square outer corners, full-height application targets.
- Dark neutral surface, white labels, system typography, blue active indicator.
- Application icons retain their real identities. SF Symbols for utility controls.
- Left-aligned running/pinned applications after the launcher control; clock and menu at right. Persistent drag ordering with a blue insertion marker.
- Quiet resting state; hover background, focus ring, running dot, active underline.
- Native context menus for window selection, pinning, reordering and application actions.
- Hover opens a compact panel above the bar after 120 ms. The first page preloads during hover intent; recent thumbnails are reused for up to five seconds while fresh captures load. Captures stop when the hover is abandoned; clicking selects the window and a separate close target closes it. Missing permissions show actionable controls with a title/icon fallback.
- Searchable launcher with keyboard navigation and clear no-results state.
- Permission explanation is actionable and disappears once access is granted.
- Respect Reduce Motion: no custom animation. Labels and accessibility hints on icon-only buttons.
